How to use DiyoFX.

A simple guide to downloading, importing and using DiyoFX presets and materials in your edits.

01

Using presets

Choose a preset from the DiyoFX Presets section and open its detail page to see the available files and links.

Download the XML preset and import it into Alight Motion. Once imported, you can replace the footage, adjust effects and customize the project for your own edit.

02

Using materials

Materials are additional resources designed to complete your edits. Depending on the package, they may include color correction, audio, overlays or additional assets.

Download the available material, extract the files when necessary, and import them into your editing project according to the type of asset.

03

XML presets

XML files are used to transfer preset settings into Alight Motion. After downloading an XML file, use the import option supported by your Alight Motion setup.

If the preset does not appear after importing, make sure the file was downloaded completely and that your Alight Motion version supports the preset.

04

Material types

CC — color correction files used to help achieve a specific visual look.

Audio — audio files included with selected material packages.

Overlay — visual elements that can be placed above your footage.

Assets — additional resources that can be used to complete or customize an edit.

05

Downloads

Always download DiyoFX files from the official website whenever possible. This helps ensure that you are using the correct and current file.

Some files may be free while selected materials or resources may require premium access.

06

Something not working?

If a file does not download or import correctly, try downloading it again and make sure the file is not corrupted.
